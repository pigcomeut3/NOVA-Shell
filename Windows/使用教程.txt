========================================
        NOVA Shell 使用教程
========================================

一、这是什么？
----------------------------------------
NOVA Shell 是一个全新设计的命令行工具，就像 Windows 的 CMD、
PowerShell，或者 Mac 的终端一样，你可以通过输入文字命令来操作电脑。

它的特点是：
  - 命令名字全部重新设计，更好记
  - 自带一个"虚拟磁盘"，在里面随便折腾不会影响电脑真实文件
  - 可以下载文件、管理进程、加密文件、玩小游戏等等


二、怎么打开？
----------------------------------------
方法：双击 NOVA Shell.exe 即可运行。


三、第一次使用
----------------------------------------
第一次打开会让你设置：
  1. 用户名（2到20个字母或数字）
  2. 密码（至少4位）
  3. 再输一遍密码确认

设置好之后会自动进入登录界面，输入刚才的用户名和密码就能用了。
以后每次打开都需要登录。


四、界面长什么样？
----------------------------------------
登录成功后会看到类似这样的一行：

  NOVA@你的用户名 路径 > 

这就是Nova Shell，你输入命令，按回车执行。

比如输入：guide  回车，就能看到所有命令的列表。

六、快捷键
----------------------------------------
  此Nova Shell无全屏快捷键
  Ctrl + C        取消当前正在运行的命令
  Ctrl + D        退出 NOVA Shell
  上箭头 / 下箭头  翻历史命令
  左箭头 / 右箭头  移动光标
  Backspace       删除光标前一个字符
  Tab             自动补全命令名和文件名，按两次显示所有选项
  右箭头          接受历史命令建议（光标在行尾时，输入过的命令会以淡绿色显示在后面，按右箭头或Tab直接补全）


七、常见问题
----------------------------------------

Q: 密码输入时为什么屏幕上什么都不显示？
A: 这是正常的安全设计，输入的密码不会显示在屏幕上，你正常输就行，
   输完按回车。

Q: 我输入了命令但提示"unknown command"怎么办？
A: 说明命令名输错了，输入 guide 可以查看所有可用命令。

Q: 虚拟磁盘里的文件关闭后还在吗？
A: 不在了。虚拟磁盘只存在于内存中，程序关闭后数据全部消失。
   重要文件请在真实模式vmode real下操作。

Q: 怎么切换到真实文件系统？
A: 输入 vmode real 回车。输入 vmode virtual 可以切回虚拟磁盘。

Q: 下载文件保存在哪里？
A: 保存在当前文件夹里。你可以用 whereami 查看当前位置，
   用 peek 查看文件是否下载成功。

Q: 程序卡住了怎么办？
A: 按 Ctrl + C 可以中断当前命令。如果完全没反应，
   直接关闭窗口重新打开即可。

八、小技巧
----------------------------------------
1. 不知道命令怎么用，就输 guide 命令名，比如 guide fetch
2. 想清空屏幕，输 wipe
3. 想快速回到用户目录，输 gohome
4. 查看文件内容用 read，编辑文件用 edit
5. 怕操作失误弄坏文件？先输 vmode virtual 进入虚拟模式随便练手
6. 想知道电脑的 IP 地址，输 address
7. 想下载文件，输 fetch 网址
8. 想加密重要文件，输 lock 文件名
9. 想看个笑话放松一下，输 joke


九、文本编辑器使用说明
----------------------------------------
edit 是一个像Markdown一样的全屏终端编辑器。

【启动】
  edit 文件名        打开或创建文件进行编辑

【界面说明】
  顶部蓝色栏：显示文件名，修改过会显示 [MODIFIED]
  中间区域：文件内容，左边有行号
  底部蓝色栏：显示快捷键和当前光标位置
  最下面一行：提示信息

【快捷键】
  方向键上下左右    移动光标
  Ctrl + S          保存文件
  Ctrl + X          退出编辑器
                      如果文件修改过，会提示你：
                      再按一次 Ctrl+X = 不保存退出
                      按 Ctrl+S = 保存后继续编辑
  Enter             换行
  Backspace         删除光标前的字符
  Delete            删除光标后的字符
  Home / End        跳到行首 / 行尾
  直接打字          在光标处插入文字

【注意】
  进入 edit 后会切换到独立的编辑界面，看不到之前的终端内容。
  按 Ctrl+X 退出后会回到 NOVA Shell 命令行。
